# 训练记录 App · 使用与安装

一个纯本地的网页 App：按你的四周渐进计划（推 → 拉 → 蹲 → 休息）提示每天练什么、记录每组的重量，带独立的计时页。不联网、不收费、不要账号。

目录：`D:\桌面\git_test\training-app\`

## 一、在电脑上看效果

直接双击 `index.html`（Chrome 或 Edge）就能用。

看手机版式：F12 → `Ctrl+Shift+M` → 选 iPhone 15 或 Pixel 7。

## 二、装到安卓手机（一次性联网）

装完就能断网用，训练时不需要网络。

1. 注册 GitHub 账号（免费，不绑卡）：github.com
2. **+ → New repository**，名字随意（如 `train`），选 **Public**
3. 进入仓库 → **Add file → Upload files**，把 `training-app` 里这 5 个文件拖进去：
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   然后 **Commit changes**
4. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch **main**、目录 **/(root)** → Save
5. 等 1 分钟，得到 `https://你的用户名.github.io/train/`
6. 手机 Chrome 打开 → 菜单 → **安装应用 / 添加到主屏幕**
7. 桌面出现图标。开飞行模式试一次，能正常用就说明离线缓存成功

以后更新：重新上传 `index.html`（改了功能就把 `sw.js` 的版本号 `trainapp-v2` 也 +1），手机上打开一次自动更新。

## 三、不想注册账号的备用方案

把 `index.html` 单独拷到手机存储，用 Chrome 打开 `file:///...`，菜单里选「添加到主屏幕」。
同样能离线用，只是顶部保留浏览器地址栏。

## 四、数据存在哪

- 存在手机浏览器本地（localStorage），不上传
- **每周去「设置 → 导出 JSON」存一份**，这是唯一保险
- 换手机：新手机装好后，「设置 → 从 JSON 导入」
- 旧版数据会自动迁移（v1 的键会被读到 v2 里，不用手动导）

## 五、功能

**五个页面**

| 页面 | 内容 |
|---|---|
| 今日 | 按周次显示当天目标；每组填重量 / 次数，打勾记录；可「排序」调整动作顺序（每天单独记） |
| 计时 | 独立页面：倒计时 / 秒表两种模式，时间自由填（分:秒），预设 60/75/90/120，开始 / 暂停 / 重置 / +15s |
| 计划 | 四天全表，渐进动作按四周展开 |
| 历史 | 大循环 → 推 / 拉 / 蹲 / 休息 → 每个动作四周的实际重量 |
| 设置 | 周次、训练日、循环切换；默认休息时长；导出导入；安装 |

**几个关键逻辑**

- **RPE 是计划值，不是填写项**：每组行首的徽章显示 `RPE6 / 12 次`（强度 + 目标次数），不记录你的 RPE
- **“上次”的取值顺序**：① 同一循环的上一周 ② 上一个大循环的同一周次 ③ 最近一次。标签会写明是「上周」「上循环」还是「最近」
- **点 ✓ 不会自动开始计时**，计时完全由你在计时页控制
- **四周一循环**：第四周标「减载周」，练完休息日自动进入下一个大循环
- **休息日三档状态**：好 / 一般 / 差，自动增减当天内容
